# sard-media

استضافة مؤقتة لفيديوهات sardhahab.com لحظة نشرها على إنستغرام وفيسبوك.

المنصتان لا تقبلان بايتات خاما — تجلبان الفيديو من رابط عام. هذا المستودع
يوفّر ذلك الرابط ولا شيء غيره.

الملفات تُرفع كـ release assets لا كملفات مستودع: الأصول خارج تاريخ git،
فتُحذف فعلا ولا ينتفخ المستودع. تحذفها مهمة `prune_archive` بعد 7 أيام.

لا شيء هنا دائم ولا مرجعي. النسخ الباقية على إنستغرام وفيسبوك وتيليجرام.
